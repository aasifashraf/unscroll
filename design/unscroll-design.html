04 · Principles

How the style was blended

We borrowed patterns that work well across the category. No layouts, artwork, icons, colors or text were copied from any product.

Style blend (internal reference)

PatternOur version
Premium dark UI with a hero metricInk base, gradient glow, Focus score ring on Home
Clear sessions and block listsBlocks hub with quick block, groups and plain-language rows
Calm interruption before openingFull-screen breathing pause with an intention prompt
Dense, readable usage statsWeek bars with a goal line, category share, stat tiles
Friendly progress and streaksGrowing plant, garden, streak chip; kind language

Rules

  • Kind, never shaming. "Instagram is resting", not "You failed".
  • Friction before force. Pause first; hard blocks are opt-in.
  • Always a way out. Strict mode shows its emergency unlock up front.
  • Privacy is visible. Onboarding, disclosures and Settings repeat "stays on this phone".
  • Color is never the only signal. Status uses icon + label; charts carry legends and values.
  • One accent. The gradient means "primary action or progress", nothing else.
  • Accessible by default. AA contrast, 48 dp targets, 200% font scale, reduced motion.
